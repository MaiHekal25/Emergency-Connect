# EmergencyConnect 🚨

**EmergencyConnect** is a simple and clean Android app built using Kotlin. It allows users to view a list of emergency contacts and initiate a call instantly by tapping a contact card. Designed for speed, simplicity, and accessibility.

---

## ✨ Features

- 📇 View emergency contacts in a modern, card-based UI  
- ☎️ Tap to call any contact directly  
- 🌗 Light and Dark theme support  
- 🎨 Material Design with custom colors and typography

---

## 🛠️ Tech Stack

| Tool           | Use                                         |
|----------------|----------------------------------------------|
| Kotlin         | Core language for Android development        |
| Material Design| UI components and themes                     |
| RecyclerView   | To display the list of contacts              |
| CardView       | For beautiful and elevated contact cards     |
| Intents        | To initiate phone calls                      |
| XML Styling    | Custom colors, themes, and text appearances  |
